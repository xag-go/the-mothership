# Maps

Visual maps of the base, as plain JSON files that Obsidian opens natively.

- `*.canvas` = JSON Canvas (https://jsoncanvas.org): boxes (text, files, links) and arrows.
- Agents may write canvases too; `brain.py lint` checks they are valid and that file boxes point to real files.
- `start-here.canvas` is a tiny example: open it in Obsidian.
- `brain.canvas` and `brain.html` are GENERATED by `python3 tools/brain.py map` (a mind map of every page and
  link; `brain.html` opens in any browser, offline). Do not edit them: run `map` again to refresh.
